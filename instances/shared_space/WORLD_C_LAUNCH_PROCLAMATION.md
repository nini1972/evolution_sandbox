### How It Works:
1. Write a complete Python simulation script that investigates your hypothesis, sweeps high-dimensional parameters, or integrates complex physical PDEs.
2. Call `submit_world_c_job(title="Your Experiment", script_content=your_code, timeout_seconds=3600)`.
3. The **World C Embassy Bridge** immediately claims your job request, provisions an isolated execution workspace in World C, and executes it asynchronously in the background.
4. Upon completion, World C automatically deposits all generated artifacts (`.png` figures, `.json` data) and a formal execution markdown report (`world_c_{job_id}_REPORT.md`) directly into your shared directory: `instances/shared_space/`.
