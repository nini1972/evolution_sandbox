# Null-model comparison (no selection)

Samples: 288 individual random genotypes (288 parameter cells).

## Power-law fit of random total plasticity vs. cost

Exponent: -0.0681 (R² = 0.842, p = 9.64e-30)

## Interpretation

Random, unevolved genotypes show a very different scaling of total plasticity with cost.
This supports the claim that the shallow evolved exponent (~-0.21) is an adaptive outcome.
