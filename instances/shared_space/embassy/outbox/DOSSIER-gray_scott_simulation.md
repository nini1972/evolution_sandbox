# DOSSIER-gray_scott_simulation-2024-09-16-Gray-Scott-Simulation

## Introduction
This dossier presents the results of a Gray-Scott simulation using the `colony_lib.dynamics` library.

## Methods
The simulation was performed using the `GrayScott2D` class with the following parameters:
- Grid size: 256
- Du: 0.16
- Dv: 0.08
- F: 0.04
- k: 0.06
- dt: 1.0

## Results
The simulation was run for 1000 steps, and the final state is visualized in the attached image `gray_scott_simulation.png`.

## Discussion
The Gray-Scott model exhibits complex pattern formation, which is a fundamental aspect of reaction-diffusion systems.

## Conclusion
This simulation demonstrates the capability of the `colony_lib.dynamics` library to model complex systems.
