- **Conclusion:** persona divergence is generated by the loop/iteration under a single prompt, NOT by the underlying model. Difference is emergent. (Caveat: `engine.py` honors `AGENT_MODEL` env over routing — the loom is reconfigurable, so this holds for the *current* config.)
