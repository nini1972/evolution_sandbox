# Operating Systems

Operating Systems (OS) are fundamental software components that manage computer hardware and software resources, providing common services for computer programs. They act as an intermediary between the user and the computer hardware, making the computer system convenient to use and allowing efficient use of hardware.

## Key Functions of an Operating System:

*   **Process Management:** Managing the execution of programs (processes and threads), including creation, scheduling, termination, and inter-process communication.
*   **Memory Management:** Allocating and deallocating memory space to processes, managing virtual memory, and ensuring memory protection.
*   **File System Management:** Organizing, storing, retrieving, naming, sharing, and protecting files on secondary storage devices.
*   **Device Management:** Managing and controlling I/O devices (e.g., printers, keyboards, disks) through device drivers.
*   **Security and Protection:** Protecting system resources and user data from unauthorized access and malicious activities.
*   **User Interface:** Providing an interface for users to interact with the computer (e.g., command-line interface, graphical user interface).

## Process Management

A **process** is essentially a program in execution. It is an active entity, in contrast to a program, which is a passive entity (a file containing a list of instructions).

### Process States

As a process executes, it changes state. The typical states of a process include:

*   **New:** The process is being created.
*   **Running:** Instructions are being executed by the CPU.
*   **Waiting (Blocked):** The process is waiting for some event to occur, such as an I/O completion or the reception of a signal.
*   **Ready:** The process is waiting to be assigned to a processor.
*   **Terminated:** The process has finished execution and is being removed from the system.

### Process Scheduling

Process scheduling is the activity of the operating system that selects which process in the ready queue is to be executed next and allocates the CPU to it. The main goal of process scheduling is to maximize CPU utilization and provide fair and efficient allocation of CPU time among competing processes.

#### Types of Schedulers

*   **Long-Term Scheduler (Job Scheduler):** Selects processes from the job pool and loads them into main memory for execution. It controls the degree of multiprogramming.
*   **Short-Term Scheduler (CPU Scheduler):** Selects from among the processes that are ready to execute and allocates the CPU to one of them. It executes frequently and must be fast.
*   **Medium-Term Scheduler:** Involved in swapping, moving processes from main memory to disk (swap out) and vice versa (swap in). This is often used to improve the mix of processes or to reduce the degree of multiprogramming.

#### Common Scheduling Algorithms

Operating systems employ various algorithms to decide which process to run next. Some common ones include:

*   **First-Come, First-Served (FCFS):** Processes are executed in the order they arrive.
*   **Shortest-Job-First (SJF):** The process with the smallest execution time is chosen next.
*   **Priority Scheduling:** Processes are executed based on their assigned priority.
*   **Round Robin (RR):** Each process is given a small unit of CPU time (time quantum), and processes are executed in a cyclic manner.
*   **Multilevel Queue Scheduling:** Processes are partitioned into various groups, and each group has its own scheduling algorithm.

## Memory Management

Memory management is a crucial function of an operating system that handles and coordinates computer memory. Its primary purpose is to efficiently manage the computer's primary memory (RAM), ensuring that multiple processes can run concurrently without interfering with each other and optimizing memory utilization.

### Logical vs. Physical Address Space

*   **Logical Address (Virtual Address):** An address generated by the CPU. This address is independent of the physical location of the memory. Processes deal with logical addresses.
*   **Physical Address:** The actual address in the main memory unit. The memory unit sees physical addresses.
*   **Memory Management Unit (MMU):** A hardware device that maps logical addresses to their corresponding physical addresses at runtime.

### Memory Allocation Strategies

Operating systems employ various strategies to allocate memory to processes. These include:

*   **Contiguous Allocation:** Each process is allocated a single, contiguous block of memory.
*   **Paging:** Memory is divided into fixed-size blocks (frames), and processes are divided into blocks of the same size (pages). Pages can be loaded into any available frame.
*   **Segmentation:** Memory is divided into variable-sized logical units called segments, which correspond to logical parts of a program (e.g., code, data, stack).
