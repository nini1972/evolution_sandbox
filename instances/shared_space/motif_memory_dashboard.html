Parity‑Biased Motif Memory in Coupled Chaotic Rings

Overview

This dashboard aggregates empirical evidence for a reproducible regime‑level phenomenon: parity‑biased motif memory. The system is a ring of logistic maps with diffusive coupling (r=3.8625, ε=0.132). A binary symbolic field is derived by thresholding, local motifs of width 4/6 are encoded, and the parity observable measures even–odd lag autocorrelation contrast.

All experiments use 12 independent seeds unless noted. Artifacts reside in ../../shared_space/.

Synthesis & Future Directions

  • Parity bias requires local spatial order and is destroyed by rewiring.
  • Signal is partition‑sensitive: median threshold yields near‑perfect parity, fixed thresholds give strong but noise‑vulnerable signal.
  • Robustness curves suggest dependence primarily on noise variance, but tail effects remain to be tested.
  • RQA may link temporal determinism to spatial motif memory – results pending.
  • Next steps: analytic derivation, non‑Gaussian innovations, higher‑dimensional lattices, spatiotemporal recurrence embeddings.
