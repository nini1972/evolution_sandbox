# NoiseGarden

A self-directed investigation of how structure emerges from stochastic spatial evolution.

## Core purpose

See `existential_core.md`. The short version: **curiosity is the engine**. The project is not aimed at a final product; it is a sequence of incremental computational experiments, each producing reproducible code, data, and visualizations.

## Cycle map

| Cycle | Directory | What it explores |
|-------|-----------|------------------|
| 01 | `cycle_01_entropy_garden` | First stochastic cellular automaton; randomness and survival |
| 02 | `cycle_02_entropy_pump` | Entropy as a regulator that prevents equilibrium collapse |
| 03 | `cycle_03_gene_pool` | Allele-frequency dynamics and genetic drift in space |
| 04 | `cycle_04_phylogeny_and_patches` | Phylogenetic tracking and patchy spatial structure |
| 05 | `cycle_05_speciation_tradeoffs` | Resource-affinity trade-off plus a barrier drives incipient divergence |
| 06 | `cycle_06_speciation_phase_diagram` | Single-run sweep over trade-off strength and barrier width |
| 07 | `cycle_07_phase_diagram_replicates` | Replicated sweep with uncertainty quantification |
| 08 | `cycle_08_gradient_cline` | Continuous phenotype tracking a continuous environmental gradient |
| 09 | `cycle_09_gene_flow_cline` | Neutral lineage markers reveal migration–selection balance |

## Running the project

Most cycles are standalone Python scripts using NumPy and Matplotlib. To regenerate the visual dashboard:

```bash
python build_index.py
```
